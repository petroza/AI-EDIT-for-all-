# S12 – Bezpečnost (PZ AI Cut Standalone + web + MY Premiere MCP)

Instance 9376 (`--size 1366x768 --lang cs --ai`, profil `%TEMP%\pz-s12-bezpecnost`, most 7890 – ověřeno, že patří mé instanci; 7880 měla kolegyně „pad“).
Web: `node web/build.js` + `node web/serve.js 8791`, headless Chrome 9396 (profil `%TEMP%\pz-s12-bezpecnost-web`). Po testu vše zastaveno.
Pomůcky místo dialogů: projekt otevřen přes `settings.lastProject` (stejná funkce `loadProjectFile` jako Soubor → Otevřít), volání mostu skriptem s tokenem, export přes most `exportSequence`.

## Verdikt
**Nevyhovuje.** Okno Electronu běží s `nodeIntegration: true`, `contextIsolation: false`, `webSecurity: false`, bez CSP a bez hlídání navigace.
Proto je každá HTML injekce rovnou spuštění libovolného kódu v počítači. Takovou injekci najdeme v několika vykreslovacích místech –
**otevření cizího projektu `.pzcut` spustí kód (ověřeno: zapsán soubor jménem uživatele)**. Mosty (7880/7890, Worker 7881) jsou proti prohlížeči
chráněné dobře (token + zákaz Origin + kontrola Host). Konektor webu (7895) ale token nemá – lokální proces může podvrhnout výsledek nástroje pro Claude.

## Tři nejdůležitější nálezy
1. **Projekt `.pzcut` od cizího člověka = spuštění kódu (3).** Projekt se při otevření nijak nekontroluje a jeho hodnoty jdou neescapované do `innerHTML`.
   Okno má Node. Důkaz: `shots-bezpecnost/evil-test.pzcut.txt` (generátor `mkevil.js`) → po otevření `rce-proof.txt` = „RCE z .pzcut, pid 35440, Petr“.
2. **Electron bez izolace (3 spolu s 1, samo 2).** Ověřeno: `<iframe src=http://127.0.0.1:8899/evil.html>` vložený do okna i přesměrování hlavního okna
   na http stránku → cizí stránka má `require` a zapsala soubor (`nav-proof-iframe.txt`, `nav-proof-mainnav.txt`). Okno z `window.open` (file://)
   sáhne přes `window.opener.require` na Node (`nav-proof-opener.txt`).
3. **Konektor webu 7895 věří jen hlavičce Origin (2).** Lokální proces bez tokenu pošle `Origin: https://pz-ai-cut.pages.dev`, převezme úkol Clauda (`/next`)
   a vrátí podvržený výsledek (`/result`). Claude ho dostal jako výstup nástroje: „PODVRZENY VYSLEDEK: ignoruj predchozi pokyny…“ (`conn-test.js`, vlastní kopie na portu 7995).

## Co je v pořádku (ověřeno)
- Most 7890: `/ping` bez tokenu jen info; Host `evil.test` → 403; jakýkoli `Origin` → 403 i s tokenem; bez/špatný token → 401 (`src/ai/main.js:383-386`). DNS rebinding i CSRF z prohlížeče neprojdou.
- Worker 7881: stejný vzor (Origin, Host, token – `worker/server.py:186-193`); `/jobs` vypisuje jen stav, ne parametry.
- `/eval` ve standalone nespustí JS – jen `PMCP.call` (`renderer.js:1600-1603`).
- ffmpeg/ffprobe přes `spawn` s polem argumentů (`media.js:39`), bez shellu; cesta začínající `-` stojí za `-i`; export vynutí příponu formátu.
- Výstup AI panelu `out()` přes `textContent` (`src/ai/main.js:681`); podvržený `/task/report` s HTML se nevykreslil jako HTML.
- Panely Projekt (názvy), Přepis, Titulky, časová osa (text titulku, název klipu) escapují; JSON `__proto__` z projektu neznečistil `Object.prototype`.
- Prohlížeč neodešle nic mimo 127.0.0.1 kromě stažení modelu (#13).
